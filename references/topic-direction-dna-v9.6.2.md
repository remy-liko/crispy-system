# 个人成长与现实认知选题 DNA｜V9.6.2

## 1｜总定位

账号前台母方向：**成年人的个人成长与现实认知**。

不是关系号、职场号、心理号，也不是泛成长鸡汤号。

统一交付：让普通成年人在真实生活里多一种识别、判断或行动能力。

题材可以宽，但每篇必须回答：

> 读者看完以后，具体会多会什么？

如果只能回答“更理解 / 更共鸣 / 更有道理”，不进入 TOP1。

---

## 2｜七个核心题群

### A｜个人成长 / 行为改变

可写：习惯、行动、拖延、恐惧、过度准备、坚持、改变。

低质量：自律、坚持、勇敢、做更好的自己。

合格方向：

- 具体卡点在哪里；
- 哪个行为反馈让人停住；
- 为什么旧做法看起来合理；
- 下一次改哪一个可观察动作。

### B｜认知纠偏

可写：常见误判、错误解释、思维惯性、反直觉结果。

低质量：提升认知、想开一点、换个角度。

合格方向：

- 读者旧解释 A 是什么；
- A 为什么解释不了现实；
- 新变量 X 是什么；
- X 怎样改变下一次判断。

### C｜能力提升

可写：表达、沟通、识人、判断、学习、决策、处理问题。

低质量：技巧清单、话术大全、多练就好。

合格方向：

- 具体场景；
- 哪一步决定效果；
- 可复用顺序 / 判断器 / 动作；
- 第二场景能否复用。

### D｜自我诊断

可写：从行为识别自己当前状态、策略或阶段。

低质量：低层次、没认知、性格有问题、人格定性。

合格方向：

- 只从可观察行为出发；
- 区分暂时策略与稳定特质；
- 解释行为背后的机制；
- 给修正入口。

### E｜人际与关系

可写：相处、边界、合作、权力、信息、隐含契约、朋友、家庭、同事。

低质量：珍惜、远离、双向奔赴、情商高低。

合格方向：

- 双方默认规则哪里不同；
- 权力 / 信息 / 资源 / 时间怎样改变行为；
- 选择造成什么后果；
- 下一次如何判断或行动。

### F｜现实选择

可写：工作、钱、家庭、人生阶段、离开 / 留下、投入 / 放弃。

低质量：泛泛谈大环境、正确态度、人生建议。

合格方向：

- 把大问题压到一个真实决定；
- trade-off 是什么；
- 哪个变量真正改变选择；
- 下一步决策顺序是什么。

### G｜机会与环境

可写：幸运、弱连接、环境、信息流、资源差异、和不同位置的人相处。

低质量：玄学幸运、成功学、人脉万能、高段位崇拜。

合格方向：

- 环境暴露；
- 信息流；
- 行为选择；
- 反馈；
- 机会成本。

## 3｜七种优先问题形态

1. **直接技能**：怎么表达、沟通、判断、学习、做决定？
2. **行为纠偏**：为什么一个看起来合理的做法反而产生坏结果？
3. **自我诊断**：哪些可观察行为说明自己正处在某种状态？
4. **认知重定义**：大家一直把 A 当问题，真正变量会不会是 B？
5. **低成本改变**：一个小动作能不能改善一个具体结果？
6. **人际能力**：怎么看人、怎么相处、怎么识别话术、怎么处理边界？
7. **现实选择**：面对工作、钱、家庭或人生阶段，怎么做更清楚的判断？

---

## 4｜知乎搜索形态

不要只搜大类：

- 职场
- 钱
- 家庭
- 关系

优先追这些问题形态：

- 为什么我明明 ________，结果却 ________？
- 怎么判断 ________？
- 哪些行为说明 ________？
- 为什么越 ________，反而越 ________？
- 一个人在 ________ 之前，应该先看什么？
- 什么看起来是优点，长期却可能带来代价？
- 有没有一种低成本方式，可以改善 ________？
- 为什么知道应该 ________，却一直做不到？
- 和 ________ 的人相处，真正该注意什么？

这些只是搜索形态，不是标题模板。

## 5｜能力收益卡

每个候选题必须补一句：

> 读者看完后会多会：________。

允许的能力收益：

- 多会一种识别；
- 多会一种判断；
- 多会一个表达 / 行动顺序；
- 多会一个可复用动作；
- 少犯一个典型误判；
- 多知道一个适用边界。

不合格：

- 更懂人生；
- 更有共鸣；
- 更理解自己；
- 提升认知；
- 学会成长。

除非继续具体到可观察、可调用的变化。

---

## 6｜Stage 03 适配

关系稿：

> 双方位置 → 选择 → 后果 → 新状态。

个人成长 / 能力稿：

> 触发 → 旧做法 → 反馈 / 后果 → 新做法 / 新判断。

自我诊断稿：

> 可观察行为 → 常见误判 → 机制 → 修正入口。

纯概念稿也必须落到具体生活场景；可以是明确标注的示意场景，不得伪装成真实经历。

---

## 7｜TOP1 终筛

同时满足：

- Demand 真实；
- Self 强；
- stakes 清楚；
- 有旧判断解释不了的缺口；
- 有明确 Ability Takeaway；
- 能形成识别信号 / 判断工具 / 下一次行动；
- 有材料发动机；
- PMT 不与近期稿件高度重复。

题材标签正确但没有能力收益：DROP。

热度高但只有围观：DROP。

共鸣强但只能写鸡汤：DROP。
